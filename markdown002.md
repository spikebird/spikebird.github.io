## Topic: Solving Linear Equations
These notes cover key concepts commonly discussed in math class when learning how to solve linear equations.

### Key Points
- Linear equations are equations where the highest power of the variable is one.
- The goal is to isolate the variable to find its value.
- Solving equations often involves using inverse operations such as addition, subtraction, multiplication, and division.

---

## Vocabulary
1. Variable: A symbol (usually a letter) that represents an unknown number.
2. Coefficient: The number multiplied by a variable.
3. Constant: A fixed value that does not change.
4. Equation: A mathematical statement that shows two expressions are equal.
5. Solution: The value of the variable that makes the equation true.
